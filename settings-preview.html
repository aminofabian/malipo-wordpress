Get set up in 3 steps

  1. Create your KioskPay account. Go to https://kioskpay.co.ke and sign up. It is free. Add where your money should land — a till, paybill, or bank account.
  2. Copy your three codes. KioskPay shows a Client ID, a Payment key, and a Signing code. Copy all three.
  3. Paste them below and save. Paste each code into the matching box, press Save changes, then press Test connection.

Connect your shop

Sign up at KioskPay, add where money lands, then copy the three codes it shows you and paste them below. You do this only once.

Find your codes in your KioskPay account under API keys — each one has a copy button. Sign in at https://kioskpay.co.ke to see them.

Client ID

Paste the Client ID from your KioskPay account. It starts with pk_live_. It is not a secret.

Payment key

Paste the Payment key from your KioskPay account. It starts with sk_live_, and is only shown once.

Signing code

Paste the Signing code from your KioskPay account. It starts with whsec_. This keeps payment confirmations secure.

API address

Leave this as it is unless KioskPay tells you otherwise.

Sends a quick check to KioskPay to confirm your payment key works.

Callback address

Already set up for you. This is where KioskPay reports each payment, and the plugin checks it before trusting it.
